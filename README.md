# Sistema de Gestión de Solicitudes Académicas

Trabajo Práctico Integrador de **Metodología de Sistemas II** (Tecnicatura Universitaria en Programación a Distancia).

Sistema de consola en Java para registrar solicitudes de estudiantes, clasificarlas por tipo, prioridad y estado, asignarles un responsable, buscarlas y generar un reporte.

> Esta es la **versión inicial** (tag `estado-inicial`): funciona, pero tiene problemas de diseño a propósito, que se diagnostican y refactorizan en las etapas siguientes.

## Requisitos

- Java 17 o superior
- Maven 3.8 o superior

## Cómo ejecutarlo

```bash
mvn package
java -jar target/sistema-solicitudes-1.0.0.jar
```
